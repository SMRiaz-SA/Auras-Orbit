## CloudStream-derived source

`android/app/src/main/java/com/lagradost/cloudstream3/utils/JsInterpreter.kt` is adapted from the CloudStream source at commit `5024ace2922a148d38df2a816b483b529789cf58`: [official source](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/utils/JsInterpreter.kt). The Orbit version removes the unavailable `Prerelease` annotation and uses Ktor's query-component decoder. CloudStream declares this source under GPL-3.0; the corresponding license is [LICENSE](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/LICENSE). The repository's GPL-3.0 `LICENSE` applies to this adapted file.

`android/app/src/main/java/com/lagradost/cloudstream3/extractors/helper/JwPlayerHelper.kt` adapts the pinned API and behavior from CloudStream commit `5024ace2922a148d38df2a816b483b529789cf58`: [official helper](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/helper/JWPlayerHelper.kt). Orbit uses its JSON mapper, bounded DNS-pinned HLS transport, and origin-aware header rules. The CloudStream compatibility reference is GPL-3.0; Orbit's GPL-3.0 license applies to this implementation.

The following Orbit extractor implementations and host aliases are source-derived from the request, callback, and class-hierarchy behavior at CloudStream commit `5024ace2922a148d38df2a816b483b529789cf58`; each pinned upstream source is GPL-3.0: [Filesim.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/Filesim.kt), [Jeniusplay.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/Jeniusplay.kt), [MixDrop.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/MixDrop.kt), [Streamlare.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/Streamlare.kt), [StreamSB.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/StreamSB.kt), [StreamTape.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/StreamTape.kt), [StreamWishExtractor.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/StreamWishExtractor.kt), and [Vidmoly.kt](https://github.com/recloudstream/cloudstream/blob/5024ace2922a148d38df2a816b483b529789cf58/library/src/commonMain/kotlin/com/lagradost/cloudstream3/extractors/Vidmoly.kt). Corresponding Orbit sources are `Filesim.kt`, `Jeniusplay.kt`, `MixDrop.kt`, `Streamlare.kt`, `Slmaxed.kt`, `StreamSB.kt`, `StreamSB8.kt`, `StreamTape.kt`, `StreamWishExtractor.kt`, `Vidmoly.kt`, and `Vidmolyme.kt` under `android/app/src/main/java/com/lagradost/cloudstream3/extractors/`.
